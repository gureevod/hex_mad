# Story 3.4: UI Framework Improvements and Technical Debt

## Status
Draft

## Story
**As a** UI test developer,
**I want** improved element configuration, better error handling, and extensibility hooks in the UI framework,
**so that** I can write more reliable tests with fine-grained control and better debugging experience.

## Background

После анализа реализации декларативного UI дизайна (см. [`ui-implementation-analysis.md`](../architecture/ui-implementation-analysis.md)) были выявлены следующие области для улучшения:
- Параметры `timeout` и `pollingInterval` из аннотаций не используются в runtime
- Отсутствует инфраструктура для interceptors/hooks
- Метод `ElementList.resolve()` выбрасывает `UnsupportedOperationException`
- Дублирование логики между `ElementBuilder` и `FieldInitializer`
- Отсутствуют готовые кастомные Conditions

## Acceptance Criteria

### AC1: Timeout и PollingInterval из аннотаций (Реализовано)
1. Параметры `timeout` и `pollingInterval` из `@Element` и `@Elements` применяются к элементам
2. Если значение -1 (default), используется глобальная конфигурация из `UiConfig`
3. Положительные значения переопределяют глобальные настройки для конкретного элемента
4. Тесты демонстрируют работу per-element timeout

### AC2: ElementInterceptor Framework (Реализовано)
1. Создан интерфейс `ElementInterceptor` с методами `beforeAction()`, `afterAction()`, `onError()`
2. `ElementInterceptorRegistry` позволяет регистрировать и управлять перехватчиками
3. `BaseElement` вызывает interceptors через шаблонный метод
4. Примеры interceptors: `ScreenshotOnErrorInterceptor`, `MetricsInterceptor`

### AC3: HexConditions - Custom WebElement Conditions (Реализовано)
1. Класс `HexConditions` содержит дополнительные условия для элементов
2. Условия: `hasClass()`, `hasDataAttribute()`, `hasAttribute()`, `isEnabled()`, `isDisabled()`
3. Условия для коллекций: `allMatch()`, `anyMatch()`, `noneMatch()`
4. Все условия интегрированы с Selenide API

### AC4: ElementList.resolve() реализация
1. Метод `resolve()` в `ElementList` корректно подставляет параметры в локатор
2. Поддержка именованных параметров: `resolve("id", "123", "status", "active")`
3. Поддержка Map параметров: `resolve(Map.of("id", "123"))`
4. Интеграция с `CompositeLocatorBuilder`

### AC5: Унификация логики создания элементов (Реализовано)
1. Создан общий `ElementCreator` для устранения дублирования между `ElementBuilder` и `FieldInitializer`
2. Логика построения локаторов вынесена в `LocatorResolver`
3. Оба класса делегируют создание элементов в общий компонент

### AC6: Улучшенные сообщения об ошибках
1. `ElementNotFoundException` с детальным контекстом (page, component, locator)
2. Подсказки для частых ошибок (неправильный xpath, элемент в iframe)
3. Автоматический скриншот при ошибке через interceptor

- [ ] Subtask 2.2: Создать `ElementInterceptorRegistry`
  ```java
  package com.company.hex.ui.interceptor;
  
  import java.util.List;
  import java.util.concurrent.CopyOnWriteArrayList;
  import java.util.Comparator;
  
  /**
   * Реестр для управления ElementInterceptor'ами.
   * Thread-safe для использования в параллельных тестах.
   */
  public final class ElementInterceptorRegistry {
      
      private static final List<ElementInterceptor> interceptors = new CopyOnWriteArrayList<>();
      
      private ElementInterceptorRegistry() {
          throw new UnsupportedOperationException("Utility class");
      }
      
      /**
       * Зарегистрировать interceptor.
       */
      public static void register(ElementInterceptor interceptor) {
          if (interceptor == null) {
              throw new IllegalArgumentException("Interceptor cannot be null");
          }
          interceptors.add(interceptor);
          sortByOrder();
      }
      
      /**
       * Удалить interceptor.
       */
      public static void unregister(ElementInterceptor interceptor) {
          interceptors.remove(interceptor);
      }
      
      /**
       * Очистить все interceptor'ы.
       */
      public static void clear() {
          interceptors.clear();
      }
      
      /**
       * Получить все зарегистрированные interceptor'ы.
       */
      public static List<ElementInterceptor> getAll() {
          return List.copyOf(interceptors);
      }
      
      private static void sortByOrder() {
          interceptors.sort(Comparator.comparingInt(ElementInterceptor::getOrder));
      }
  }
  ```

- [ ] Subtask 2.3: Добавить вызов interceptors в `BaseElement`
  ```java
  // BaseElement.java
  
  /**
   * Выполнить действие с вызовом interceptors.
   */
  protected <T> T executeWithInterceptors(String actionName, Object[] args, Supplier<T> action) {
      List<ElementInterceptor> interceptors = ElementInterceptorRegistry.getAll();
      
      // Before
      for (ElementInterceptor interceptor : interceptors) {
          try {
              interceptor.beforeAction(this, actionName, args);
          } catch (Exception e) {
              logger.warn("Interceptor beforeAction error: {}", e.getMessage());
          }
      }
      
      T result = null;
      Exception error = null;
      
      try {
          result = action.get();
      } catch (Exception e) {
          error = e;
      }
      
      // After or onError
      for (ElementInterceptor interceptor : interceptors) {
          try {
              if (error == null) {
                  interceptor.afterAction(this, actionName, result);
              } else {
                  interceptor.onError(this, actionName, error);
              }
          } catch (Exception e) {
              logger.warn("Interceptor {} error: {}", 
                  error == null ? "afterAction" : "onError", e.getMessage());
          }
      }
      
      if (error != null) {
          throw error instanceof RuntimeException 
              ? (RuntimeException) error 
              : new RuntimeException(error);
      }
      
      return result;
  }
  
  /**
   * Упрощенная версия для void методов.
   */
  protected void executeWithInterceptors(String actionName, Object[] args, Runnable action) {
      executeWithInterceptors(actionName, args, () -> {
          action.run();
          return null;
      });
  }
  ```

  ```java
  package com.company.hex.ui.interceptor;
  
  import com.codeborne.selenide.Selenide;
  import com.company.hex.ui.core.BaseElement;
  import io.qameta.allure.Allure;
  import org.slf4j.Logger;
  import org.slf4j.LoggerFactory;
  
  import java.io.ByteArrayInputStream;
  
  /**
   * Interceptor для автоматического скриншота при ошибке.
   */
  public class ScreenshotOnErrorInterceptor implements ElementInterceptor {
      
      private static final Logger logger = LoggerFactory.getLogger(ScreenshotOnErrorInterceptor.class);
      
      @Override
      public void onError(BaseElement element, String actionName, Exception exception) {
          try {
              byte[] screenshot = Selenide.screenshot(OutputType.BYTES);
              if (screenshot != null) {
                  String name = String.format("Screenshot_%s_%s_error", 
                      element.getName().replaceAll("\\s+", "_"), actionName);
                  Allure.addAttachment(name, "image/png", new ByteArrayInputStream(screenshot), ".png");
                  logger.debug("Screenshot captured for {} error on '{}'", actionName, element.getName());
              }
          } catch (Exception e) {
              logger.warn("Failed to capture screenshot: {}", e.getMessage());
          }
      }
      
      @Override
      public int getOrder() {
          return 10; // Выполняется рано для захвата состояния
      }
  }
  ```

  ```java
  package com.company.hex.ui.interceptor;
  
  import com.company.hex.ui.core.BaseElement;
  import org.slf4j.Logger;
  import org.slf4j.LoggerFactory;
  
  import java.util.Map;
  import java.util.concurrent.ConcurrentHashMap;
  import java.util.concurrent.atomic.AtomicLong;
  
  /**
   * Interceptor для сбора метрик выполнения действий.
   */
  public class MetricsInterceptor implements ElementInterceptor {
      
      private static final Logger logger = LoggerFactory.getLogger(MetricsInterceptor.class);
      
      private final Map<String, AtomicLong> actionCounts = new ConcurrentHashMap<>();
      private final Map<String, AtomicLong> errorCounts = new ConcurrentHashMap<>();
      private final ThreadLocal<Long> actionStartTime = new ThreadLocal<>();
      
      @Override
      public void beforeAction(BaseElement element, String actionName, Object[] args) {
          actionStartTime.set(System.currentTimeMillis());
          actionCounts.computeIfAbsent(actionName, k -> new AtomicLong()).incrementAndGet();
      }
      
      @Override
      public void afterAction(BaseElement element, String actionName, Object result) {
          long duration = System.currentTimeMillis() - actionStartTime.get();
          logger.trace("Action '{}' on '{}' completed in {}ms", actionName, element.getName(), duration);
      }
      
      @Override
      public void onError(BaseElement element, String actionName, Exception exception) {
          errorCounts.computeIfAbsent(actionName, k -> new AtomicLong()).incrementAndGet();
          logger.debug("Action '{}' on '{}' failed: {}", actionName, element.getName(), exception.getMessage());
      }
      
      public Map<String, Long> getActionCounts() {
          Map<String, Long> result = new ConcurrentHashMap<>();
          actionCounts.forEach((k, v) -> result.put(k, v.get()));
          return result;
      }
      
      public Map<String, Long> getErrorCounts() {
          Map<String, Long> result = new ConcurrentHashMap<>();
          errorCounts.forEach((k, v) -> result.put(k, v.get()));
          return result;
      }
  }
  ```

  ```java
  package com.company.hex.ui.conditions;
  
  import com.codeborne.selenide.WebElementCondition;
  import org.openqa.selenium.WebElement;
  
  /**
   * Дополнительные условия для проверки UI элементов.
   * Расширяет стандартные Selenide Condition.
   */
  public final class HexConditions {
      
      private HexConditions() {
          throw new UnsupportedOperationException("Utility class");
      }
      
      /**
       * Проверить, что элемент имеет указанный CSS класс.
       */
      public static WebElementCondition hasClass(String className) {
          return new WebElementCondition("has class '" + className + "'") {
              @Override
              public boolean test(WebElement element) {
                  String classes = element.getAttribute("class");
                  if (classes == null) return false;
                  
                  // Проверяем точное совпадение класса, не подстроки
                  for (String cls : classes.split("\\s+")) {
                      if (cls.equals(className)) {
                          return true;
                      }
                  }
                  return false;
              }
          };
      }
      
      /**
       * Проверить, что элемент НЕ имеет указанный CSS класс.
       */
      public static WebElementCondition notHasClass(String className) {
          return new WebElementCondition("not has class '" + className + "'") {
              @Override
              public boolean test(WebElement element) {
                  return !hasClass(className).test(element);
              }
          };
      }
      
      /**
       * Проверить, что элемент имеет data-атрибут с указанным значением.
       */
      public static WebElementCondition hasDataAttribute(String dataAttr, String value) {
          String fullAttr = "data-" + dataAttr;
          return new WebElementCondition("has " + fullAttr + " = '" + value + "'") {
              @Override
              public boolean test(WebElement element) {
                  String attrValue = element.getAttribute(fullAttr);
                  return value.equals(attrValue);
              }
          };
      }
      
      /**
       * Проверить, что элемент имеет data-атрибут (любое значение).
       */
      public static WebElementCondition hasDataAttribute(String dataAttr) {
          String fullAttr = "data-" + dataAttr;
          return new WebElementCondition("has " + fullAttr) {
              @Override
              public boolean test(WebElement element) {
                  return element.getAttribute(fullAttr) != null;
              }
          };
      }
      
      /**
       * Проверить, что атрибут элемента соответствует regex.
       */
      public static WebElementCondition attributeMatches(String attr, String regex) {
          return new WebElementCondition("attribute '" + attr + "' matches '" + regex + "'") {
              @Override
              public boolean test(WebElement element) {
                  String value = element.getAttribute(attr);
                  return value != null && value.matches(regex);
              }
          };
      }
      
      /**
       * Проверить, что элемент имеет указанный CSS стиль.
       */
      public static WebElementCondition hasCssValue(String property, String value) {
          return new WebElementCondition("has CSS " + property + " = '" + value + "'") {
              @Override
              public boolean test(WebElement element) {
                  String cssValue = element.getCssValue(property);
                  return value.equals(cssValue);
              }
          };
      }
      
      /**
       * Проверить, что элемент находится в viewport (видим пользователю).
       */
      public static WebElementCondition inViewport() {
          return new WebElementCondition("in viewport") {
              @Override
              public boolean test(WebElement element) {
                  // Используем JavaScript для проверки
                  org.openqa.selenium.Rectangle rect = element.getRect();
                  int windowHeight = ((org.openqa.selenium.JavascriptExecutor) 
                      com.codeborne.selenide.WebDriverRunner.getWebDriver())
                      .executeScript("return window.innerHeight;");
                  int windowWidth = ((org.openqa.selenium.JavascriptExecutor) 
                      com.codeborne.selenide.WebDriverRunner.getWebDriver())
                      .executeScript("return window.innerWidth;");
                  
                  return rect.getX() >= 0 && rect.getY() >= 0 
                      && rect.getX() + rect.getWidth() <= windowWidth
                      && rect.getY() + rect.getHeight() <= windowHeight;
              }
          };
      }
      
      /**
       * Проверить, что элемент disabled (для кнопок, input и т.д.).
       */
      public static WebElementCondition beDisabled() {
          return new WebElementCondition("disabled") {
              @Override
              public boolean test(WebElement element) {
                  return !element.isEnabled() 
                      || "true".equals(element.getAttribute("disabled"))
                      || element.getAttribute("class").contains("disabled");
              }
          };
      }
      
      /**
       * Проверить, что элемент readonly.
       */
      public static WebElementCondition beReadonly() {
          return new WebElementCondition("readonly") {
              @Override
              public boolean test(WebElement element) {
                  return "true".equals(element.getAttribute("readonly"))
                      || element.getAttribute("readonly") != null;
              }
          };
      }
      
      /**
       * Проверить, что элемент пустой (нет текста и value).
       */
      public static WebElementCondition beEmpty() {
          return new WebElementCondition("empty") {
              @Override
              public boolean test(WebElement element) {
                  String text = element.getText();
                  String value = element.getAttribute("value");
                  return (text == null || text.isEmpty()) 
                      && (value == null || value.isEmpty());
              }
          };
      }
      
      /**
       * Проверить placeholder текстового поля.
       */
      public static WebElementCondition hasPlaceholder(String placeholder) {
          return new WebElementCondition("has placeholder '" + placeholder + "'") {
              @Override
              public boolean test(WebElement element) {
                  return placeholder.equals(element.getAttribute("placeholder"));
              }
          };
      }
  }
  ```

  ```java
  package com.company.hex.ui.conditions;
  
  import com.codeborne.selenide.WebElementsCondition;
  import com.codeborne.selenide.impl.CollectionSource;
  import org.openqa.selenium.WebElement;
  
  import java.util.List;
  import java.util.function.Predicate;
  
  /**
   * Условия для проверки коллекций элементов.
   */
  public final class HexCollectionConditions {
      
      private HexCollectionConditions() {
          throw new UnsupportedOperationException("Utility class");
      }
      
      /**
       * Все элементы соответствуют условию.
       */
      public static WebElementsCondition allMatch(Predicate<WebElement> predicate, String description) {
          return new WebElementsCondition() {
              @Override
              public void check(CollectionSource collection) {
                  List<WebElement> elements = collection.getElements();
                  for (int i = 0; i < elements.size(); i++) {
                      if (!predicate.test(elements.get(i))) {
                          throw new AssertionError(String.format(
                              "Element [%d] does not match: %s", i, description));
                      }
                  }
              }
              
              @Override
              public String toString() {
                  return "all match: " + description;
              }
          };
      }
      
      /**
       * Хотя бы один элемент соответствует условию.
       */
      public static WebElementsCondition anyMatch(Predicate<WebElement> predicate, String description) {
          return new WebElementsCondition() {
              @Override
              public void check(CollectionSource collection) {
                  List<WebElement> elements = collection.getElements();
                  for (WebElement element : elements) {
                      if (predicate.test(element)) {
                          return; // Нашли подходящий
                      }
                  }
                  throw new AssertionError("No element matches: " + description);
              }
              
              @Override
              public String toString() {
                  return "any match: " + description;
              }
          };
      }
      
      /**
       * Ни один элемент не соответствует условию.
       */
      public static WebElementsCondition noneMatch(Predicate<WebElement> predicate, String description) {
          return new WebElementsCondition() {
              @Override
              public void check(CollectionSource collection) {
                  List<WebElement> elements = collection.getElements();
                  for (int i = 0; i < elements.size(); i++) {
                      if (predicate.test(elements.get(i))) {
  ```

  ```java
  package com.company.hex.ui.locator;
  
  import java.util.Map;
  import java.util.regex.Matcher;
  import java.util.regex.Pattern;
  
  /**
   * Утилита для работы с параметризованными локаторами.
   */
  public final class LocatorResolver {
      
      private static final Pattern PLACEHOLDER_PATTERN = Pattern.compile("\\{([^}]+)\\}");
      private static final Pattern PRINTF_PATTERN = Pattern.compile("%[sdf]");
      
      private LocatorResolver() {
          throw new UnsupportedOperationException("Utility class");
      }
      
      /**
       * Подставить именованные параметры в локатор.
       * Формат: {paramName}
       */
      public static String resolve(String locator, Map<String, String> params) {
          if (locator == null || params == null || params.isEmpty()) {
              return locator;
          }
          
          Matcher matcher = PLACEHOLDER_PATTERN.matcher(locator);
          StringBuffer result = new StringBuffer();
          
          while (matcher.find()) {
              String paramName = matcher.group(1);
              String value = params.get(paramName);
              if (value == null) {
                  throw new IllegalArgumentException(
                      "Missing parameter '" + paramName + "' for locator: " + locator);
              }
              matcher.appendReplacement(result, Matcher.quoteReplacement(value));
          }
          matcher.appendTail(result);
          
          return result.toString();
      }
      
      /**
       * Подставить параметры по порядку (varargs).
       * Формат: %s, {0}, {1}
       */
      public static String resolve(String locator, String... params) {
          if (locator == null || params == null || params.length == 0) {
              return locator;
          }
          
          // Сначала пробуем printf-style
          if (PRINTF_PATTERN.matcher(locator).find()) {
              return String.format(locator, (Object[]) params);
          }
          
          // Затем пробуем {0}, {1} style
          String result = locator;
          for (int i = 0; i < params.length; i++) {
              result = result.replace("{" + i + "}", params[i]);
          }
          
          return result;
      }
      
      /**
       * Проверить, что локатор содержит плейсхолдеры.
       */
      public static boolean hasPlaceholders(String locator) {
          if (locator == null) return false;
          return PLACEHOLDER_PATTERN.matcher(locator).find() 
              || PRINTF_PATTERN.matcher(locator).find();
      }
  }
  ```
