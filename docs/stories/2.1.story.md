# Story 2.1: Core Declarative API Framework (MVP)

## Status
Approved

## Story
**As an** API test developer,
**I want** a core declarative interface pattern similar to Retrofit2,
**so that** I can define API contracts with minimal boilerplate and get type-safe responses for basic CRUD operations.

## Acceptance Criteria
1. A minimal set of core annotations are available in `hex-core-api` for defining API endpoints:
   - `@ApiService` for service-level configuration (e.g., `baseUrl`).
   - HTTP method annotations: `@GET`, `@POST`.
   - Parameter annotations: `@Path`, `@Query`, `@Body`.
2. The `ApiServiceFactory.create(MyApi.class)` method can generate a working client from an annotated interface.
3. The factory uses a modular, proxy-based architecture (handler, processor, executor, converter).
4. Method return types support typed DTOs (e.g., `UserDto`) and `List<UserDto>` with automatic JSON deserialization.
5. A sample `UserApi` interface and corresponding `UserDto` are created in the `hex-project-samples` module to demonstrate usage.
6. A basic test exists that uses the generated `UserApi` client to execute a `GET` request and successfully deserializes the response into a typed DTO.

## Dev Notes

### MVP Focus
This story focuses exclusively on the foundational elements required for a pure-declarative API layer. The goal is to establish the core pattern and prove its viability. Advanced features like interceptors, authentication, extended annotations (`@PUT`, `@DELETE`, `@Header`, `@Retry`, etc.), and complex type handling will be addressed in subsequent stories.

We are replacing the dummy `BaseApiService` implementation with this new modular, proxy-based approach.

### Core Components
- **`AnnotationProcessor`**: Parses interface methods and their annotations to create a `RequestDefinition`.
- **`RequestDefinition`**: A simple DTO that holds all the metadata needed to make an HTTP call (method, path, parameters, body).
- **`RequestExecutor`**: Takes a `RequestDefinition` and uses RestAssured to execute the actual HTTP request.
- **`ResponseConverter`**: Converts the `Response` from RestAssured into the Java type defined in the interface method signature.
- **`ProxyHandler`**: The central orchestrator. It intercepts method calls on the generated API client, uses the `AnnotationProcessor` to get a `RequestDefinition`, passes it to the `RequestExecutor`, and finally uses the `ResponseConverter` to return the typed result.
- **`ApiServiceFactory`**: The public entry point that puts everything together and returns a fully functional API client instance.
