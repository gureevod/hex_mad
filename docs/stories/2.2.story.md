# Story 2.2: Advanced Declarative Features & Extensibility

## Status
Draft

## Story
**As an** API test developer,
**I want** advanced declarative features and an extension mechanism,
**so that** I can handle a wider range of API testing scenarios including authentication, error handling, and other HTTP methods.

## Acceptance Criteria
1.  Full support for all standard HTTP methods is added: `@PUT`, `@DELETE`, `@PATCH`.
2.  Additional parameter annotations are implemented: `@Header`, `@FormParam`.
3.  An interceptor system is in place, allowing custom logic to be added to the request/response lifecycle.
4.  A `LoggingInterceptor` is created and enabled by default to provide visibility into requests and responses.
5.  An `@ExpectedStatus` annotation is available to specify the expected HTTP status code for a request, with automatic validation.
6.  An `@Retry` annotation is implemented to allow for automatic retries on failed requests.
7.  The sample `UserApi` is updated to include examples of the new annotations (`@PUT`, `@DELETE`, `@Header`, `@ExpectedStatus`).

## Dev Notes

### Extensibility via Interceptors
The interceptor system is the key to extensibility. It allows for cross-cutting concerns to be handled in a clean, reusable way. The flow will be:
`ProxyHandler -> InterceptorChain -> RequestExecutor`

This allows for logic to be executed before and after the actual HTTP request. This is the ideal place for:
-   Authentication (e.g., adding an `Authorization` header).
-   Logging.
-   Metrics collection.
-   Request/response transformation.
-   Caching.

### Feature Breakdown
- **Full CRUD**: With `@PUT`, `@DELETE`, and `@PATCH`, the framework now fully supports all standard CRUD operations.
- **Error Handling**: `@ExpectedStatus` provides a simple, declarative way to assert the correctness of API responses.
- **Resiliency**: The `@Retry` annotation makes tests more robust against transient network or service failures.
- **Flexibility**: `@Header` and `@FormParam` unlock a wider variety of API interaction patterns.
